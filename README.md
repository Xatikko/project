Компиляция

Для сборки программы выполните команду:
bash

gcc main.c filesystem.c -o fs_program

Описание файлов

filesystem.h
Заголовочный файл содержит объявления следующих функций:

    create_open_file

    view_file

    delete_file

    add_file

    modify_file

filesystem.c
Функция create_open_file

Принимает имя файла. Если файл отсутствует, он создаётся. Если файл уже существует, он открывается. Возвращает файловый дескриптор.
Функция view_file

Принимает имя файла и открывает его для чтения. Выводит содержимое с начала файла, добавляя символ новой строки после каждой строки.
Функция delete_file

Принимает имя файла. Если файл существует, он удаляется. В противном случае выводится сообщение об ошибке.
Функция add_file

Принимает имя нового файла. Если файл с таким именем уже есть, возвращает ошибку. Затем запрашивает имя существующего файла, содержимое которого будет скопировано в новый файл.

Пример использования:

Введите имя нового файла: new_file.txt  
Введите имя существующего файла: source.txt  

Функция modify_file

Принимает имя файла. Если файл существует, его содержимое полностью перезаписывается (через создание временного файла, который затем заменяет оригинальный). Если файла нет, возвращается ошибка.
Подключение библиотеки

Чтобы использовать функции, добавьте в начало программы:
c

#include "filesystem.h"
